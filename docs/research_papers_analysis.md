# 핵심 연구 논문 분석 및 요약

본 문서는 CAN-IDS 프로젝트의 기반이 되는 3개의 핵심 논문에 대한 상세한 분석과 프로젝트 구현에 필요한 기술적 세부사항을 정리한 내용입니다.

## 1. CAN-BERT: Controller Area Network Intrusion Detection System based on BERT Language Model (2022, Alkhatib et al.)

### 1.1 연구 배경 및 문제 정의

**배경**
- 현대 자동차의 ECU 통합 증가와 네트워크 연결성 향상으로 인한 보안 취약성 증가
- CAN 버스는 암호화 및 인증 메커니즘 부재로 메시지 주입 공격에 취약
- 기존 자기회귀 모델(RNN, GPT 등)은 왼쪽 문맥만 고려하여 CAN ID 시퀀스의 전체 문맥 정보 표현 능력 한계

**문제 정의**
- CAN ID 시퀀스의 전체 컨텍스트(좌우 양방향)를 학습하여 알려진 및 미지의 사이버 공격을 정확하고 실시간으로 탐지할 수 있는 효과적인 침입 탐지 시스템 개발

### 1.2 제안 방법론

**핵심 아이디어**
- BERT 언어 모델의 양방향 인코더(Bidirectional Encoder) 특성을 활용하여 CAN ID 시퀀스의 왼쪽 및 오른쪽 컨텍스트 동시 학습
- 비지도 학습 방식의 "마스크된 언어 모델(Masked Language Model, MLM)" 목표 사용

**작동 방식**
1. 입력 CAN ID 시퀀스에서 임의의 비율(m=0.45)로 일부 CAN ID를 마스크 토큰으로 대체
2. CAN-BERT 모델이 마스크된 CAN ID의 원래 ID를 양방향 컨텍스트 기반으로 예측
3. 마스크된 CAN ID 예측 확률 분포와 실제 CAN ID 간의 교차 엔트로피 손실 최소화로 훈련
4. 이상 탐지 시 실제 CAN ID가 모델 예측한 상위 K개 후보에 포함되지 않으면 비정상으로 판단

### 1.3 모델 아키텍처

**구성 요소**
- **입력**: CAN ID 시퀀스 `S = [id1, ..., idt, ..., idT]`
- **식별자 임베딩**: 각 CAN ID를 d차원 공간으로 선형 투영
- **위치 임베딩**: 사인 함수를 사용한 위치 정보 인코딩
- **트랜스포머 인코더**: L개(L=4) 레이어 스택
  - 멀티-헤드 셀프-어텐션(H=1)
  - 포지션-와이즈 피드-포워드 네트워크
  - 잔차 연결 및 레이어 정규화
- **출력 레이어**: d차원 벡터를 M차원(CAN ID 집합 크기)으로 투영

**주요 하이퍼파라미터**
- 트랜스포머 인코더 레이어 수: 4
- 모델 차원: 256
- 피드-포워드 네트워크 차원: 512
- 어텐션 헤드 수: 1
- 드롭아웃: 0.1
- 마스크 비율: 0.45
- 배치 크기: 32
- 학습률: 0.001

### 1.4 실험 결과

**데이터셋**
- Car Hacking: Attack & Defense Challenge 2020 데이터셋
- 쉐보레 스파크, 현대 쏘나타, 기아 쏘울 정지 상태 데이터
- 공격 유형: Flooding, Fuzzy, Malfunction

**성능 결과**
- F1-score: 0.85-0.99 (시퀀스 길이 T > 32)
- 추론 시간: 0.8-3.1ms (실시간 탐지 가능)
- 모델 크기: 20-70MB
- 파라미터 수: 2-3백만 개

### 1.5 프로젝트 구현 참고사항

**기술적 세부사항**
- MLM 사전 훈련 방식 채택
- 양방향 문맥 학습의 중요성
- 마스크 비율 0.45 최적화
- 실시간 탐지 가능한 경량 모델 설계

## 2. LSF-IDM: Automotive Intrusion Detection Model with Lightweight Attribution and Semantic Fusion (2023, Cheng et al.)

### 2.1 연구 배경 및 문제 정의

**배경**
- 복잡한 딥러닝 모델(BERT, GPT-2)의 높은 성능 vs 경량 모델의 자원 효율성 사이의 균형 필요
- IVN의 제한된 컴퓨팅 및 저장 자원, 높은 실시간성 요구사항
- 기존 경량 모델의 문맥 기반 공격 탐지 성능 한계

**문제 정의**
- 높은 탐지 성능과 낮은 모델 복잡도를 동시에 만족하는 자동차 침입 탐지 모델 개발
- 문맥 의미 특징을 경량 모델로 효율적으로 전달하는 방법 필요

### 2.2 제안 방법론

**핵심 아이디어: 지식 증류(Knowledge Distillation) 기반 교사-학생 패러다임**

**세부 단계**
1. **교사 모델(BERT)**: 복잡한 문맥 의미 특징 추출
2. **학생 모델(BiLSTM/DNN)**: 경량 모델로 침입 탐지 수행
3. **지식 증류**: 교사 모델의 지식(출력 확률 분포, 문맥적 특징)을 학생 모델로 전달

**손실 함수**
- 결합 손실: `L = α * L_CE(학생 예측, 실제 레이블) + (1 - α) * L_KD(학생 소프트 예측, 교사 소프트 타겟)`
- 온도 파라미터 T를 사용한 소프트 타겟 생성

### 2.3 모델 아키텍처

**교사 모델 (CAN-BERT)**
- 12개 트랜스포머 블록, Hidden size 768, 약 1.1억 파라미터
- 입력: 토큰화된 CAN 메시지 (ID, DLC, Data Field), Max length 16
- 출력: 분류를 위한 로짓 (소프트 타겟 생성용)

**학생 모델 (BiLSTM)**
- Hidden size 64, LSTM 레이어 2개
- 양방향 LSTM의 은닉 상태 결합
- 경량 설계로 실제 차량 환경 배포 가능

**지식 증류 메커니즘**
- 소프트 타겟 생성: `P_i = exp(Z_i/T) / Σ_j exp(Z_j/T)`
- 교사-학생 간 확률 분포 유사성 학습

### 2.4 실험 결과

**데이터셋**
- HCRL 자동차 해킹 데이터셋
- 공격 유형: DoS, Fuzzy, RPM, GEAR
- 정상 데이터: 훈련 9,826,105개, 테스트 4,211,188개

**성능 결과**
- DoS 공격: 99.28% ACC, 99.99% F1-score
- 스푸핑 공격: 100% ACC, PRE, REC, F1-score
- Fuzzy 공격: 정밀도 10.43%↑, F1-score 3.16%↑ (vs BiLSTM 단독)
- 교사 모델 대비 유사한 성능, 파라미터 수 대폭 감소

### 2.5 프로젝트 구현 참고사항

**기술적 세부사항**
- 지식 증류 기반 경량화 방법론
- 교사-학생 패러다임 구현
- 소프트 타겟 및 온도 파라미터 활용
- 실시간 배포 가능한 경량 모델 설계

## 3. Intrusion Detection Using Transformer in Controller Area Network (2024, Jo & Kim)

### 3.1 연구 배경 및 문제 정의

**배경**
- 커넥티드 카 확산으로 인한 사이버 공격 취약성 증가
- CAN 프로토콜의 인증/암호화 메커니즘 부재
- 기존 IDS의 한계: 통계 기반 방법의 다차원 데이터 처리 한계, 딥러닝 기반 방법의 지도 학습 의존성

**문제 정의**
- 제한된 컴퓨팅 자원 환경에서 CAN 버스 사이버 공격을 효과적으로 탐지
- CAN 메시지의 시간적(CAN ID 시퀀스) 및 공간적(페이로드) 특성 동시 고려

### 3.2 제안 방법론

**핵심 아이디어**
- 트랜스포머의 시퀀스 데이터 분석 능력을 CAN 데이터에 적용
- CAN 메시지를 언어 모델의 "토큰"으로, 시퀀스를 "문장"으로 간주
- 시간적/공간적 데이터 동시 분석하는 투-스트림 아키텍처

**비지도 학습 방식**
- 정상 CAN 데이터 학습으로 정상 패턴 모델링
- 다음 CAN ID 예측 방식: 예측 불일치 시 공격으로 판단
- 레이블링 없이 알려진/미지의 공격 모두 탐지 가능

### 3.3 모델 아키텍처

**투-스트림 아키텍처**
- **CAN ID 시퀀스 트랜스포머**: 시간적 흐름 분석
- **페이로드 시퀀스 트랜스포머**: 공간적 내용 분석
- **결합 예측**: 두 트랜스포머 출력의 벡터 덧셈으로 최종 예측

**개별 트랜스포머 구성**
- Input Embedding Layer: 토큰을 E차원 벡터로 변환
- Positional Encoding: 학습 가능한 위치 정보 주입
- L개 트랜스포머 블록 (L=4)
  - Multi-head Self-Attention (4개 헤드)
  - Feed Forward Network (ReLU 활성화)
  - Residual Connection & Layer Normalization
- Linear Layer: E차원을 N차원(CAN ID 클래스 수)으로 변환

**데이터 전처리**
- CAN ID 값 분리: 모든 CAN ID에 256 추가 (ID: 256-2303, 페이로드: 0-255)
- DLC 처리: 빈 슬롯을 Void 토큰(<2304>)으로 채움
- 슬라이딩 윈도우: CAN ID 시퀀스 16/32/64 토큰, 페이로드 시퀀스 9 토큰

### 3.4 실험 결과

**데이터셋**
- HCRL 현대 쏘나타 실제 CAN 데이터셋
- 정상 데이터: 117,173개
- 공격 유형: Flooding, Fuzzy, Malfunction

**성능 결과**
- 윈도우 사이즈 증가에 따른 성능 향상
- 시간적-공간적 분석 결합으로 기존 트랜스포머 기반 모델 대비 우수한 성능
- 추론 시간: 0.0689ms/프레임 (실시간 탐지 가능)
- 예측 범위 확장으로 오탐 감소 효과

### 3.5 프로젝트 구현 참고사항

**기술적 세부사항**
- 오프셋 기반 통합 어휘집 방법론
- ID+페이로드 통합 시퀀싱 방법
- 투-스트림 아키텍처 설계
- 예측 범위 확장을 통한 강건성 향상

## 4. 프로젝트 구현을 위한 통합 분석

### 4.1 공통 핵심 기술

**1. 트랜스포머 기반 아키텍처**
- 양방향 문맥 학습 능력
- 멀티-헤드 셀프-어텐션 메커니즘
- 위치 인코딩 중요성

**2. 비지도 학습 방식**
- MLM (Masked Language Model) 목표
- 정상 데이터만을 이용한 패턴 학습
- 다음 토큰 예측 방식

**3. 경량화 기법**
- 지식 증류 (Knowledge Distillation)
- 교사-학생 패러다임
- 실시간 배포 가능한 모델 설계

### 4.2 데이터 처리 방법론

**1. 오프셋 기반 통합 어휘집 (Jo & Kim, 2024)**
- CAN ID와 페이로드 값 범위 분리
- 통일된 토큰 체계 구축

**2. 시퀀스 처리**
- 슬라이딩 윈도우 방식
- 시간적-공간적 특성 동시 고려
- 적절한 시퀀스 길이 선택 (32-64 토큰)

### 4.3 성능 최적화 전략

**1. 하이퍼파라미터 최적화**
- 마스크 비율: 0.45 (CAN-BERT)
- 어텐션 헤드 수: 1-4개
- 임베딩 차원: 64-256
- 온도 파라미터: 지식 증류 시 중요

**2. 평가 지표**
- F1-score 중심 평가 (불균형 데이터 고려)
- 추론 시간 측정 (실시간성 확보)
- 오탐률(FPR) 최소화

### 4.4 구현 우선순위

**Phase 1: 기본 CAN-BERT 모델**
- MLM 기반 사전 훈련
- 기본 트랜스포머 아키텍처 구현
- 정상 데이터 패턴 학습

**Phase 2: 분류 모델 개발**
- 사전 훈련된 모델 기반 미세 조정
- 다양한 공격 유형 탐지
- 성능 평가 및 최적화

**Phase 3: 경량화 적용**
- 지식 증류 기법 적용
- 학생 모델 훈련
- 실시간 배포 최적화

이 분석은 프로젝트의 기술적 방향성과 구현 전략 수립에 핵심적인 참고 자료로 활용될 것입니다.
